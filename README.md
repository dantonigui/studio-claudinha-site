# Studio Claudinha Website

A responsive website that presents Studio Claudinha's beauty services and helps visitors request an appointment.

## Highlights

- Service catalog with descriptions and pricing.
- WhatsApp links to ask about available appointment times.
- Studio location and contact details.
- Responsive layout for mobile and desktop.

## Built with

- HTML5
- CSS3
- Google Fonts: Cormorant Garamond and Montserrat

## Live site

[studio-claudinha.vercel.app](https://studio-claudinha.vercel.app)

## Run locally

Open `index.html` in a browser. No build step is required. The fonts are loaded from Google Fonts.
